Detailed Description

Classe na qual representa um dispositivo de iluminação automatizado. A classe Luz herda de Dispositivo e permite controlar a intensidade da luz (níveis de 1 a 5).
Além disso, esse sistema consegue detectar erros/falhas que prejudicam o funcionamento.
