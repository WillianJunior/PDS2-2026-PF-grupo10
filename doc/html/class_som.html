Detailed Description

Dispositivo conectado ao sistema que executa as funcoes de tocar e gerenciar musicas. A classe Som herda de Dispositivo e permite controlar a lista de faixas tocando agora, adicionar novas faixa, remover faixas, alterar o volume e o estado (ligado/desligado). Alem disso, esse sistema consegue detectar erros/falhas que prejudicam o funcionamento.
