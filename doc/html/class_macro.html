Detailed Description

Representa uma macro de ações associadas a um evento. Permite agrupar múltiplas ações sobre diferentes dispositivos. Esse agrupamento é feito por uma lista encadeada, onde cada nó contém o dispositivo e a operação a ser executada sobre ele.
